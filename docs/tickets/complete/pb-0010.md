# PB-0010 — Cover image: editable URL, SVG support, dark-mode display

- **Scope / acceptance criteria (one testable concern: the admin can set a post's cover image,
  including an SVG, and it displays correctly in both themes):**
  - `PostForm` gets a "Cover image URL" text input (create + edit), prefilled from
    `post.cover_image_url` when editing; `createPost`/`updatePost` parse and persist it
    (empty string → `null`, matching the existing `excerpt` convention) — previously the
    `cover_image_url` column existed on `posts` but nothing in the admin UI could set it.
  - The image uploader (`ImageUpload.tsx` + `admin/(protected)/posts/upload/route.ts`) accepts
    `image/svg+xml` alongside PNG/JPEG/WEBP/GIF, client-side `accept` and server-side
    allowlist/extension map both updated, error copy updated to mention SVG.
  - `PostCard`'s cover image gets `dark:invert` (flips a line-art SVG's colors to read against
    dark backgrounds) and `block mx-auto` (centers it now that it renders at a fixed width
    instead of stretching full-card-width).
  - AC: `npm run lint` and `npx tsc --noEmit` pass; setting a cover image URL (including an
    uploaded SVG's URL) on a post persists across create/edit and renders centered, inverted in
    dark mode, on the post list card.
- **Per-ticket context:** follow-on from [PB-0009](pb-0009.md)'s admin polish — the cover image
  field was a known gap (see `.claude/references/data-model.md`, which already documented the
  Storage-upload-then-URL-into-content flow but not a cover-image path). SVG support and the
  invert/center styling were requested together once the admin started using an SVG as a cover
  image.
  - **Known caveat, deliberately not addressed here:** the post *detail* page
    (`posts/[slug]/page.tsx`) renders its cover image via `next/image` without
    `dangerouslyAllowSVG` in `next.config.ts`, so an SVG cover image will fail to render there
    even though it now uploads fine and displays fine on `PostCard`. Also, `dark:invert` applies
    to any cover image, not just SVGs — a photographic cover image would look wrong in dark
    mode. Both are flagged for a future ticket, not fixed here.
- **Files touched:** `app/admin/(protected)/posts/PostForm.tsx`,
  `app/admin/(protected)/posts/actions.ts`, `app/admin/(protected)/posts/ImageUpload.tsx`,
  `app/admin/(protected)/posts/upload/route.ts`, `app/(public)/PostCard.tsx`.
- **Rough size:** tiny, <60 lines.
- **Depends on:** PB-0004 (image upload), PB-0009 (cover image field sits alongside that
  ticket's admin polish).
